# PistonMeta v0.3 — GitHub Pages

面向 Al-Si-Cu-Mg 活塞铝合金的金相图像辅助分割与定量工作台。纯静态 HTML/CSS/JavaScript，图像在浏览器本地处理，不调用云端 API。

## 部署
仓库包含 GitHub Actions Pages 工作流。提交到 `main` 后，工作流会配置 GitHub Pages 并发布站点；也可以在 Actions 标签页查看部署状态。

发布网址： https://ustbTobyMa.github.io/pistonmeta/

## 功能
- 上传金相图、三类视觉组织分割与面积比例统计
- 标尺候选识别、手动两点标定；需人工确认后才输出 μm 单位
- 连通域数量、等效圆直径、长宽比和粒径分布
- 画笔修正、撤销、批量分析
- 导出 CSV、HTML 报告和 ZIP 检测包；支持重新导入检测包
- 样本批次、组织状态、检测人员和复核备注

## 重要限制
分割类别表示视觉颜色类别，不是化学物相鉴定。不能仅凭光学金相颜色直接判定 Si、富 Fe 或富 Cu 相。正式质检前需要使用人工标注真值进行精度、重复性和再现性验证，并通过 SEM/EDS 确认真实相类型。系统不会自动给出材料合格/不合格结论。

公开仓库只存放网页代码和合成演示图，不要提交企业保密金相图片、个人信息或 API 密钥。上传的检测图像只在用户浏览器本地处理；导出的检测包由使用者自行保管。
